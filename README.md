# GTA Tax Training (unofficial)

Source-cited training guides for taxes administered by General Tax Administration (GTA), Florida Department of Revenue.
**Unofficial training aid, not legal advice. Florida law and official Department publications control.**

- Live site: https://shea-nelson.github.io/gta-tax-training/
- First guide: Florida Sales and Use Tax, at [`/sut/`](https://shea-nelson.github.io/gta-tax-training/sut/). It has 18 modules, a learning path, a glossary, a form finder, a quick reference, and sources and method.

## Layout
| Path | What |
|---|---|
| `docs/` | Built static site served by GitHub Pages: plain HTML, CSS and vanilla JS, with no CDNs |
| `content/home.html`, `content/<tax>/` | Page fragments, `site.json` (page registry), `quizzes.json`, `figures/*.svg` |
| `content/sources.json` | Citation keys mapped to official floridarevenue.com URLs, generated by `tools/sources_seed.py` |
| `tools/harvest.py` | Polite crawler and downloader: honest user agent, 1.2 s delay, robots.txt honored, no sign-in |
| `tools/build.py` | Builder. Macros: `{{cite:KEY}}`, `{{svg:NAME}}`, `{{quiz}}`, `{{modules}}`. Fails on unknown cite keys, modules citing fewer than 3 sources, missing quizzes, heading-order problems and duplicate ids |
| `tools/make_forms.py` | Generates the form finder from the harvested forms index |
| `tools/linkcheck.py` | Polite external link check |
| `tests/` | `taxcalc.test.js` (calculator unit tests), `check.mjs` (axe-core WCAG 2.2 AA, 320 px reflow, focus, links and interactions), `facts.py` (claims checked against source text) |
| `source/manifest.json` / `.csv` | Every harvested file: URL, type, title, number, revision date, fetch time and SHA-256. The files are not committed (about 420 MB) |

## Adding the next tax
1. Add `content/<tax>/site.json`, its page fragments and `quizzes.json`.
2. Add any new sources with `tools/sources_seed.py`.
3. Call `build_tax('<tax>')` in `tools/build.py` and add the guide card to `content/home.html`.

## Rebuild and test
```
python3 tools/build.py
node --test tests/taxcalc.test.js
python3 tests/facts.py
(cd docs && python3 -m http.server 47123) &  cd tests && npm i && node check.mjs http://127.0.0.1:47123
```
